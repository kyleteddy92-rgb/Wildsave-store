# Wildsave Electrical Store

Full-stack starter with customer storefront, server-side admin login, SQLite backend, products and orders.

Run:
1. Install Node.js 20+
2. `npm install`
3. `npm start`
4. Open `http://localhost:3000/`
5. Admin: `http://localhost:3000/admin.html`

Default demo admin: admin / ChangeMe123!
Change it before publishing. For production add HTTPS, a strong SESSION_SECRET, rate limiting, CSRF protection, backups, and a real payment provider.
